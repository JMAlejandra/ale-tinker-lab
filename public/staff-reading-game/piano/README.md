# Piano samples

Salamander Grand Piano V3 by Alexander Holm, licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

These are the MP3 conversions from the Tone.js audio repository
(github.com/Tonejs/audio), used unmodified. The 17 samples (C, D#, F# and A
from C2 to C6; `Ds` = D sharp, `Fs` = F sharp) are played by the staff reading
game sound engine, which pitch-shifts the nearest sample to reach other notes.
